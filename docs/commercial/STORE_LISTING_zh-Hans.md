## 完整描述

gm-console 是 Ada 平台的移动端伴侣。Ada 是面向运维团队的开源低代码数据流水线引擎，
帮助他们交付 ETL 工作流而无需手工搭建管道。

在 iOS / Android 上使用 gm-console，你可以：

- **检查流水线** — 实时查看每个采集、转换、导出任务的状态
- **触发任务** — 按需启动 / 暂停 / 重启任务
- **监控事故** — 关心的工作区事件以推送通知送达
- **审计与恢复** — 查看近期自愈记录，重跑失败任务，导出运行日志
- **多租户感知** — 切换工作区，权限由上游强制执行
- **离线容忍** — 缓存最近 24 小时仪表盘，在线时全功能

底层：gm-console 与 Ada api-gateway 通信，所有数据停留于你运营的部署内。我们不会
把你的流水线数据存到我们的服务器。

开源、AGPL v3 + 书面同意附加条款（WRITTEN CONSENT）。详见应用内附带的 LICENSE。
