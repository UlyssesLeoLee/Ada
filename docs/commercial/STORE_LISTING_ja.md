## 完全な説明

gm-console は Ada プラットフォームのモバイルコンパニオンアプリです。Ada は ETL ワークフロー
を手書き配管なしで出荷したい運用チーム向けの、オープンソース・ロウコードのデータパイプラ
インエンジンです。

gm-console を iOS または Android で使うと、次のことができます。

- **パイプラインの確認** — 各収集・変換・エクスポータの稼働状態をライブ表示
- **ジョブのトリガ** — 必要に応じてタスクを開始 / 一時停止 / 再起動
- **インシデントの監視** — 関心のあるテナントイベントをプッシュ通知で受信
- **監査と復旧** — 最近のリメディエーションの確認、失敗ジョブの再実行、実行ログのエクスポート
- **テナント対応** — 操作対象のワークスペースを切り替える。上流で RBAC を強制
- **オフライン耐性** — 過去 24 時間のダッシュボードをキャッシュ。オンライン時は全機能

仕組み: gm-console は Ada api-gateway と通信し、データはあなたが運用するデプロイメント内
に留まります。パイプラインデータを当社のサーバーに保存することは一切ありません。
