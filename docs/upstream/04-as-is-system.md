| レイヤ | 技術 | 備考 |

| 業務システム | 各社 SaaS | API / CSV 連携 |

## 4. データフロー

| 段階 | 入力 | 処理 | 出力 | 所要時間 |
|---|---|---|---|---|
| 取得 | 業務システム API / CSV | ポーリング / ファイルコピー | 中間 DB raw テーブル | 30 分 |
| 変換 | raw テーブル | 結合・集計・型変換 | 整形済テーブル | 1-2 時間 |
| ロード | 整形済テーブル | Snowflake へ COPY | DWH テーブル | 30 分 |
| 公開 | DWH | Tableau ビュー | ダッシュボード | 即時 |

## 6. 課題

詳細は [DOC-UP-005 課題一覧](05-issue-list.md) 参照。

主要課題:

1. **PostgreSQL 12 EOL**: 2024 年 11 月 EOL、未アップグレード
2. **RLS 不在**: マルチテナント分離が DB レベルで不在
3. **手動デプロイ**: Jenkins 夜間手動、ヒューマンエラー多発
4. **属人化**: 特定データエンジニアに依存
5. **監視不足**: Datadog 設定が浅く、障害発見が遅い
6. **Informatica ライセンス**: 年間 1,000 万円
7. **バッチのみ**: リアルタイム性なし
