## 3. 影響力 / 関心度マトリクス

```
関心度  ↑
高   │  SH-E-01   SH-I-03   SH-I-04   SH-I-10
     │  SH-I-05   SH-I-06   SH-I-11   SH-I-12
     │  SH-I-13
     │─────────────────────────────────────
中   │  SH-I-01   SH-I-02   SH-I-07   SH-I-14
     │  SH-E-02   SH-E-03   SH-E-05   SH-E-08
     │─────────────────────────────────────
低   │  SH-E-04   SH-E-07   SH-I-15
     │
低 ←── 影響力 ──→ 高
```

### 3.1 対応方針

| 象限 | 戦略 | 適用 |
|---|---|---|
| 高影響 × 高関心 | **重点管理**（密な連携） | SH-I-03, SH-I-04, SH-I-05, SH-I-11, SH-I-13 |
| 高影響 × 低関心 | **満足させる**（情報提供） | SH-I-01, SH-I-02, SH-E-04, SH-E-07 |
| 低影響 × 高関心 | **情報提供**（随時共有） | SH-I-12, SH-E-08 |
| 低影響 × 低関心 | **最小限の労力** | SH-E-04, SH-E-07, SH-I-15 |

## 5. コミュニケーション計画

詳細は [DOC-MGT-COM-001 コミュニケーション計画](../management/04-communication-plan.md) 参照。

| 種別 | 頻度 | 参加者 | 媒体 |
