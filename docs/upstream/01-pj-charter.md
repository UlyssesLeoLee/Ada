## 2. ビジョン・ミッション

### 2.1 ビジョン

> 「無数の業務データを **無限のキャンバス** 上で可視化し、ノードとしてつなぎあわせ、コードを書かずに業務フローを再構築できる世界を実現する」

### 2.2 ミッション

1. **データ統合の民主化**：技術者でなくても、視覚的にデータソースを接続・変換できる
2. **無限の表現力**：固定的なダッシュボードに縛られず、自由に画布を構築・拡張できる
3. **リアルタイム性**：ストリーミング／バッチ／イベント駆動を統合的に扱う
4. **エンタープライズ対応**：マルチテナント、RBAC、監査、可用性を標準装備

### 2.3 経営目標との整合

| 経営目標 | 本プロジェクトの貢献 | 測定指標 |
|---|---|---|
| 業務データ活用の加速 | ノーコードで ETL を構築 | 構築工数 1/10 |
| データサイロの解消 | 多様なデータソース対応 | 対応コネクタ数 ≥ 20 |
| リアルタイム意思決定 | ストリーミング + イベント駆動 | レイテンシ < 1s |
| グローバル展開 | 多言語 + マルチテナント SaaS | 3 リージョン対応 |

## 3. スコープ

### 3.1 In-Scope（含む）

| 区分 | 範囲 |
|---|---|
| 機能 | 16 モジュール（[DOC-MOD-001〜016](../modules/M-01-acquisition-adapter.md)）+ 管理画面 + 公開 API |
| プラットフォーム | macOS / Linux / Windows 3 OS 対応 |
| デプロイモード | 単機 / SaaS / ハイブリッド 3 モード |
| データソース | REST, DB, File, gRPC, WS 対応（5 種以上） |
| 言語 | UI = 多言語（i18n 基盤）、Rust runtime = 英語ログ |
| 規模 | 10k ノード/画布、100 同時編集ユーザー、1 万テナント |
| コンプライアンス | GDPR / PIPL（[NF-SEC](../architecture/03-cross-cutting-risks.md)） |

### 3.2 Out-of-Scope（含まない）

| 区分 | 範囲 | 理由 |
|---|---|---|
| モバイルアプリ | iOS / Android | 第 2 フェーズ |
| ネイティブプラグイン | 専用ハードウェア連携 | 要件未定 |
| AI 機能 | 自動 ETL 推薦 / 異常検知 | 将来検討 |
| BaaS フル機能 | ログ・監視 SaaS のフル機能 | 部分的対応 |
| ホスティング | マネージド提供 | 顧客責任 |

### 3.3 スコープ変更管理

- スコープ変更は [DOC-TPL-CHG §A.1 CR チケット](../templates/06-change-management.md#a1-変更要求チケットipa-工程-118) で起票
- 承認: PO + PM + アーキ の 3 名合議
