## 1. リスク評価基準

| 影響度 | 説明 | スコア |
|---|---|---|
| 極大 | プロジェクト中止レベル | 5 |
| 大 | 大幅遅延・予算超過 | 4 |
| 中 | 一部機能影響 | 3 |
| 小 | 軽微 | 2 |
| 極小 | 影響軽微 | 1 |

| 発生確率 | 説明 | スコア |
|---|---|---|
| 極高 | 確実 | 5 |
| 高 | 高い | 4 |
| 中 | 中程度 | 3 |
| 低 | 低い | 2 |
| 極低 | ほぼ無い | 1 |

| スコア | 対応優先度 |
|---|---|
| 16-25 | 極大（即対応） |
| 10-15 | 大（即検討） |
| 5-9 | 中（計画化） |
| 1-4 | 小（受容も可） |

## 8. 監視計画

- **月次レビュー**: 全リスク再評価
- **週次**: 極大・大リスクの状況確認
- **トリガー時**: 新リスク発生時は即時追加

| 監視項目 | 頻度 | 担当 |
|---|---|---|
| 人員状況 | 週次 | PM |
| 性能ベンチマーク | 週次 | アーキ |
| 法令変更 | 月次 | SecO |
| 競合動向 | 四半期 | PO |
| 監査ログ | リアルタイム | SRE |

## 9. 用語集

| 用語 | 説明 |
|---|---|
| リスク | 不確実な事象で影響度と発生確率を持つ |
| リスクスコア | 影響度 × 発生確率 |
| 対応戦略 | 回避 / 軽減 / 受容 / 転嫁 |
| KT | Knowledge Transfer |
