## 2. F-01 〜 F-17 詳細

### F-01 无限画布エディタ

| 項目 | 内容 |
|---|---|
| 概要 | 視覚的な ETL / 業務フロー構築 UI |
| アクター | 業務部門、データエンジニア |
| 入力 | ユーザー操作（マウス、タッチ） |
| 出力 | キャンバス JSON |
| 受け入れ条件 | (1) 10,000 ノード表示 (2) パン / ズーム 60fps (3) 共同編集 100 同時 |
| 関連 NF | [NF-PER] 1k node 操作 < 100ms |
| 担当 M-ID | [M-12](../modules/M-12-canvas-editor-frontend.md) |

### F-02 データ取得アダプタ

| 項目 | 内容 |
|---|---|
| 概要 | 多様なデータソースへの接続・データ取得 |
| アクター | データエンジニア（プラグイン開発）、業務部門（設定） |
| 入力 | 接続情報（URL、認証） |
| 出力 | 統一された raw メッセージ |
| 受け入れ条件 | (1) 5 種以上対応 (REST, DB, File, gRPC, WebSocket) (2) CDC 対応 (3) プラグインで 1 週間以内追加 |
| 関連 NF | [NF-PER] 取得 < 100ms |
| 担当 M-ID | [M-01](../modules/M-01-acquisition-adapter.md) |

### F-03 データ標準化

| 項目 | 内容 |
|---|---|
| 概要 | 異なるデータソースを NJSON (F-10) に統一 |
| アクター | システム（自動） |
| 入力 | raw メッセージ |
| 出力 | NJSON |
| 受け入れ条件 | 100% 変換成功 / エラーは監査ログへ |
| 関連 NF | — |
| 担当 M-ID | [M-02](../modules/M-02-normalizer.md) |

### F-04 データフローエンジン

| 項目 | 内容 |
|---|---|
| 概要 | キャンバス上のノードを順次/並列実行 |
| アクター | システム |
| 入力 | キャンバス定義、NJSON |
| 出力 | 実行結果 |
| 受け入れ条件 | 100 ステップを 10 秒以内、1k ノード並列実行 |
| 関連 NF | [NF-PER] 1k node < 100ms |
| 担当 M-ID | [M-03](../modules/M-03-data-flow-engine.md) |

### F-05 オーケストレーション

| 項目 | 内容 |
|---|---|
| 概要 | パイプライン全体の制御（依存関係、並列度） |
| アクター | システム |
| 入力 | キャンバス定義、トリガー |
| 出力 | 実行指示 |
| 受け入れ条件 | DAG ベース、依存解決 100ms 以内 |
| 関連 NF | — |
| 担当 M-ID | [M-04](../modules/M-04-orchestration-engine.md) |

### F-06 制御フロー実行

| 項目 | 内容 |
|---|---|
| 概要 | 条件分岐、ループ、並列分岐 |
| アクター | システム |
| 入力 | キャンバス定義、実行コンテキスト |
| 出力 | 次ノード |
| 受け入れ条件 | (1) 100 ネスト (2) 無限ループ検知 |
| 関連 NF | — |
| 担当 M-ID | [M-05](../modules/M-05-control-flow-executor.md) |

### F-07 プラグイン SDK

| 項目 | 内容 |
|---|---|
| 概要 | カスタムノード、データソースを開発する SDK |
| アクター | データエンジニア |
| 入力 | ソースコード |
| 出力 | プラグイン JAR / wasm |
| 受け入れ条件 | (1) Rust SDK (2) ホットスワップ対応 (3) サンドボックス実行 |
| 関連 NF | — |
| 担当 M-ID | [M-06](../modules/M-06-node-runtime-plugin-sdk.md) |

### F-08 デバッグサービス

| 項目 | 内容 |
|---|---|
| 概要 | ブレークポイント、ステップ実行、トレース |
| アクター | データエンジニア |
| 入力 | デバッグ指示 |
| 出力 | 実行状態、変数 |
| 受け入れ条件 | (1) ノード単位ステップ (2) 変数 watch (3) トレースログ |
| 関連 NF | — |
| 担当 M-ID | [M-07](../modules/M-07-debug-service.md) |

### F-09 免インストール/単一バイナリ

| 項目 | 内容 |
|---|---|
| 概要 | バイナリ 1 つで全機能動作、ブラウザでアクセス |
| アクター | エンドユーザー |
| 入力 | なし（プリインストール） |
| 出力 | 動作するシステム |
| 受け入れ条件 | (1) 単一バイナリ < 200MB (2) 3 OS 対応 (3) ブラウザで全機能 |
| 関連 NF | [NF-ENV] 3 OS 必須 |
| 担当 M-ID | [M-12](../modules/M-12-canvas-editor-frontend.md), [M-13](../modules/M-13-api-gateway.md) |

### F-10 標準化 JSON (NJSON)

| アクター | システム |
| 入力 | 任意 |
| 出力 | NJSON 形式 |
| 受け入れ条件 | JSON Schema で定義、バージョン管理 |
| 関連 NF | — |

### F-11 RBAC + 协作

|---|---|

| 出力 | 許可/拒否 |
