## 3. ユーザーシナリオ

### 3.1 田中（営業企画）の 1 日

```
08:00  出社、ブラウザを開く → 昨日までの売上推移を確認（自動）
09:00  新規キャンペーン用のデータソースを追加（GUI）
10:00  キャンペーン効果を分析するためのダッシュボード作成（ドラッグ＆ドロップ）
12:00  ランチ
14:00  同僚の鈴木と画布を共有、共同編集
15:00  結果を上司に共有
17:00  退社
```

### 3.2 鈴木（データエンジニア）の週

```
月 09:00  複雑な変換要件のレビュー
月 14:00  プラグイン SDK でカスタムコネクタ開発
火       テスト、CI
水       デバッグ機能で障害追跡
木       本番リリース（atomic swap、5 分）
金       監視レビュー、チューニング
```
