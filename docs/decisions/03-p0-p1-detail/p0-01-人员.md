## §1 背景 / 問題

[`docs/architecture/06-rust-tech-selection.md` §18](../../../architecture/06-rust-tech-selection.md) で 16 crate + 2 共有 crate = 18 個の Rust crate 構造を定義したが、**実装者が 0 名**。Rust 専門人材の確保が G4 实施着手判定の最大ブロッカー。

QA 登録簿 §5.1 UN-P0-01 期限: **実装着手 -7 日**、Owner: **マネージャ**。

## §2 决策

**採用案**: **Option C (Solo + AI 補助) と Option B (段階採用) 併用**

- 当面（1-3 月）: Solo + AI 補助で核心 2-3 crate（`M-13 API Gateway`、`M-10 テナント`、`M-15 イベントバス`）を実装
- 段階採用（3-6 月）: 並行して 2-4 名を採用・教育、残り crate を委譲

## §3 選択肢と評価

### Option A: 16 名内部採用

- **优点**: 全 crate を自前管理、品質統一、ナレッジ蓄積
- **缺点**: 採用コスト高（年俸 ×16）、採用期間 4-6 月、雇用リスク
- **リスク**: Rust 専門人材は市場希少、採用難 → 計画遅延
- **可逆性**: 低（採用後解雇困難）

### Option B: 4-6 名コア + 外注併用 ⭐ 推奨

- **优点**: コア部分は自前、汎用 crate は外注で工数削減
- **缺点**: 外部依存（コード品質・スケジュール）、契約管理コスト
- **リスク**: ベンダロックイン、特定企業への集中
- **可逆性**: 中（外注契約終了可能、内部採用は容易ではない）

### Option C: Solo + AI 補助 ⭐ 推奨（当プロジェクト）

- **优点**: 即時着手、AI で 3-5x 速度向上、低コスト、Solo 意思決定の速さ
- **缺点**: 単一障害点（バスファクタ 1）、知識属人化、AI 品質ばらつき
- **リスク**: 体調・事故で進行停止、レビュー品質
- **可逆性**: 高（いつでも採用・外注追加可能）

### Option D: 外部 1 社一括委託

- **优点**: 短期間（1 月）で全 crate 着手、PM コスト削減
- **缺点**: ベンダロックイン、知的財産権問題、品質ばらつき
- **リスク**: 委託先破綻時の事業継続性
- **可逆性**: 低（途中切替困難）

## §5 期限 / 触发条件

- **决策期限**: 2026-08-27（即時）
- **採用着手**: 2026-09-01
- **再评估触发**:
  - AI 補助の生産性が期待値（3-5x）未達の場合 → Option B へ加速
  - 採用 1 名目の不成約が 3 ヶ月継続 → 外注比率引き上げ

## §6 影响範囲 / リスク

- **影响模块**: 全 16 crate（[`crates/`目录](../../../crates/)）、G4 实施着手判定
- **リスク评估**:
  - 単一障害点: Solo の体調・事故 → 進捗 0
  - 知識属人化: Solo → 他者への引き継ぎ困難
  - AI 品質ばらつき: コードレビュー必須、自動テスト必須
- **緩和策**:
  - 全 commit を Git 記録、AI 補助ログ保存
  - 月次コードレビュー会（Solo 以外の 1 名必須参加）
  - 重要 crate（M-13, M-10, M-15）から着手、3 月以内に段階採用
