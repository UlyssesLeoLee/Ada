## §1 背景 / 問題

QA 登録簿 §5.2 UN-P1-13: **QA-T05 UX 検証計画**、期限: **M-12 着手 -3 日**、Owner: **プロダクト + ユーザ**。

[`crates/ada-canvas-ui/`](../../../crates/) (M-12) のユーザビリティ検証計画（被験者、テスト方法、合否基準）が未策定。事業目標「8 割の業務ユーザがゼロコードで完結」([`docs/architecture/00-anatomy-model.md` §5](../../../architecture/00-anatomy-model.md)) の達成度未測定。

## §2 决策

**採用案**: **5-8 名ユーザビリティテスト + AARRR ファネル + 月次改善サイクル**

- **被験者**: 5-8 名（業務ユーザのペルソナ別）
- **テスト方法**:
  - タスクベース（キャンバス作成、ノード配置、プラグイン利用）
  - 観察 + インタビュー（60 分 / 人）
  - 定量: タスク完了率、時間、エラー数
- **合否基準**:
  - タスク完了率 ≥ 80%（事業目標連動）
  - 平均完了時間 ≤ 5 分
  - SUS (System Usability Scale) ≥ 70
- **頻度**: β 開始時、v1.0、v2.0（3 フェーズ必須）

## §3 選択肢と評価

### Option A: 5-8 名ユーザビリティテスト + AARRR ⭐ 推奨

- **优点**: Nielsen 推奨のテスト人数、量的・質的データ両立
- **缺点**: 被験者リクルートコスト、時間
- **リスク**: バイアス（IT 慣れユーザ偏り）
- **可逆性**: 高

### Option B: A/B テストのみ

- **优点**: 大量データ、統計的信頼性
- **缺点**: 質的フィードバック得にくい、初期は未実施
- **リスク**: 早期 UX 問題の見逃し
- **可逆性**: 中

### Option C: 自動メトリクス（ヒートマップ等）のみ

- **优点**: 低コスト、持続的
- **缺点**: 「なぜ」の情報なし
- **リスク**: 表面的な最適化
- **可逆性**: 高

### Option D: 専門家レビュー（ヒューリスティック）

- **优点**: 低コスト、即時
- **缺点**: 実ユーザ視点欠如
- **リスク**: ユーザの声を反映できない
- **可逆性**: 高
