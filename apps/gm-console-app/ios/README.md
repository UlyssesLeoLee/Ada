> `flutter create --platforms=ios --org dev.kanvas .` from this directory on a host with

## Permissions (NSUsageDescription)

gm-console Mobile's first release does NOT request:
- Camera, Photos, Microphone — not needed at v0.3.0.
- Location — N/A for the runbook features shipped.
- Contacts / Calendar / Health — N/A.

If/when incident attachments land, `NSCameraUsageDescription`,
`NSPhotoLibraryUsageDescription`, `NSPhotoLibraryAddUsageDescription` must be added with
explicit user-facing strings.

  `https://gm-console.kanvas.dev/.well-known/apple-app-site-association`.

## Signing posture

- Distribution: **App Store Connect** (no ad-hoc, no enterprise).
- Certificate type: **Apple Distribution** (managed by Xcode automatic signing OR a
  manual profile checked into a password manager — never into git).
- Capabilities: Push (initial), App Groups (later), Sign in with Apple (deferred).
- Keychain Sharing group: `dev.kanvas.gmconsole.shared` (forward-compat only — not
  enabled at v0.3.0).

## Bring-up commands

```bash
# On a macOS host with Xcode 15+ and Flutter 3.24.5 (per apps/gm-console-app/.flutter-version):
cd apps/gm-console-app
flutter create --platforms=ios --org dev.kanvas --project-name gm_console_app .

# Then open ios/Runner.xcworkspace and set:
#   Signing & Capabilities → Team: Ada Project Team
#   Build Settings → DEPLOYMENT_POSTPROCESSING = YES
#   Build Phases → Embed App Extensions = NO (avoid static plug-in linker bloat)

flutter build ios --release
open ios/build/ios/Release/Runner.xcarchive   # verify, then upload with xcrun altool.
```

## What is NOT in git

| What                                          | Why                                                |
|-----------------------------------------------|----------------------------------------------------|
| `ios/Pods/`                                   | regenerated by `pod install` — `.gitignore`        |
| `ios/.symlinks/`, `ios/Flutter/Generated.xcconfig` | regenerated by `flutter pub get`                  |
| `ios/Runner.xcworkspace/xcuserdata/*`         | Xcode user state — `.gitignore`                    |
| `*.p12`, `*.cer`, `*.mobileprovision`        | credentials — never in git; OIDC +1Password only  |
| `GoogleService-Info.plist`                    | push key — sealed-secret only                      |

CI integration lives in `.github/workflows/release.yml` (release tag) — and a new
`mobile-build.yml` is the worker-G target.
